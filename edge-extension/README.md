# 秋招工作台助手 · Edge 扩展

连接本地「秋招工作台」(`http://127.0.0.1:8787`) 的浏览器扩展，提供**一键捕捉岗位**的能力：

1. **一键捕捉岗位** —— 在 BOSS / 牛客 / 公司官网上看到心仪岗位，点插件 → 「捕捉当前页岗位」，
   插件先**按站点只抓右侧详情面板**（排除左侧岗位列表干扰），再用 **DeepSeek 智能解析**公司 / 岗位 / 薪资 / 城市 / 经验 / 学历 / JD，
   你确认/修改后 → 加入工作台「岗位池」。（DeepSeek 未配置时自动回退本地启发式。）

## 前置条件

- 工作台本地服务正在运行（`uvicorn` 监听 `127.0.0.1:8787`）。

## 在 Edge 中加载（开发者模式）

1. 打开 `edge://extensions`
2. 右上角打开 **开发人员模式**（Developer mode）
3. 点 **加载解压缩的扩展**（Load unpacked）
4. 选择本目录 `edge-extension/`
5. 固定插件到工具栏，开始使用

> Chrome 同理：`chrome://extensions` → 开发者模式 → 加载解压缩的扩展。

## 权限说明

- `activeTab` / `scripting`：读取当前页并注入页面提取脚本。
- `storage`：本地缓存。
- `host_permissions` 含 `http://127.0.0.1:8787/*`（工作台 API）与 `<all_urls>`（任意招聘/官网页可捕捉）。

## 文件

- `manifest.json` —— MV3 清单
- `popup.html / popup.css / popup.js` —— 弹出页（捕捉入口）
- `background.js` —— Service Worker，中转 API 调用（绕过扩展页 CORS）

## 捕捉增强（v0.2.x）

- **站点感知提取（解决「左侧列表被混入」）**：`extractPage` 对 BOSS/牛客/拉勾/猎聘/LinkedIn 按 host 排除左侧列表/侧边栏选择器
  （如 BOSS 的 `.job-list` / `.job-card-wrapper`），只抓右侧「岗位详情主面板」；通用回退找含「职位描述/岗位职责」的最大容器。
  这是你截图里左侧一列岗位被误抓的根因修复，**无需 LLM 也生效**。
- **DeepSeek 智能解析（smart-capture）**：扩展把「干净详情文本」发给本地服务 `/api/extension/smart-capture`，
  后端复用工作台已配置的 DeepSeek（`deepseek-chat`，`json_mode`）解析出
  `company / title / salary / location / experience / education / job_type / jd_text / deadline / publish_date`，弹窗预填你确认。
  **实测**：模拟 BOSS 详情文本 → 公司=星轨科技、岗位=UI设计师、薪资=12-20K·13薪、城市=杭州、经验=1-3年、学历=本科、来源=BOSS直聘，全部正确。
  DeepSeek 未配置或解析失败时，自动回退 `guessJob` 启发式（确认制，结果以你核对的为准）。
- **公司 / 来源网站分离**：`guessJob` 用「岗位关键词」（设计/产品/运营/开发/经理…）判别职位段与公司段，
  并对「腾讯招聘」「UI设计师招聘」这类尾巴自动剥掉「招聘」；**公司绝不会被识别成网站名**（BOSS直聘/牛客/拉勾/猎聘/LinkedIn 等进入黑名单守卫）。
- **空格分隔标题也支持**：切分符在 `[-_｜|]` 基础上增加**空格**（牛客校招标题多为 `字节跳动 前端开发工程师 校招 牛客网`、官网 h1 多为 `网易 交互设计师 招聘`），
  并剔除独立的「招聘/校招/社招/实习/内推」词段，再落公司/岗位；避免公司被识别为空只能手填。
- **来源网站 = 公司官方招聘站（联网检索）**：捕捉到公司名后，扩展自动调用本地服务
  `/api/extension/find-company-site`，后端先用**搜索引擎（默认 DuckDuckGo，无需 Key）全网检索** `{公司} 官网 招聘`，
  再让已配置的 LLM（DeepSeek）从候选结果里挑出「带招聘入口的官方站」（jobs./careers./campus. 子域优先，排除 BOSS/牛客等平台）。
  结果自动填入「来源网站」输入框；**弹窗里你可手动改**。检索失败/无网时优雅回退到招聘平台名（BOSS直聘等）。
  **实测**：`find-company-site({company:"字节跳动"})` → `https://jobs.bytedance.com/`（DeepSeek 判定为官方招聘站）。
- **来源可追溯**：捕捉保存时，若「来源网站」已是官方站 URL，则 `source` 与 `source_url` 都写该官网（岗位池卡片「🌐 来源」点开即进官网）；
  若仍是平台名，则 `source_url` 退回原抓取页 URL。

## 真实站点可抓取性测试清单

> 捕捉逻辑依赖页面标题格式，且需要你已登录的会话。最终「在浏览器里点一下」这一步请你在自己的登录会话里走一遍；
> 下面是在开发环境对**真实标题格式**做的端到端实测结论（复跑 `guessJob` + 对本地 `/api/extension/capture` 回环，沙箱无法登录 BOSS/牛客 故不直连其网页）。

| 站点 | 模拟页面标题 / h1 | 实测结果（修复后） |
| --- | --- | --- |
| BOSS直聘 岗位详情 | `UI设计师-腾讯-BOSS直聘` | 来源=BOSS直聘；公司=腾讯；岗位=UI设计师 ✓ |
| 牛客 校招（空格标题） | `字节跳动 前端开发工程师 校招 牛客网` | 来源=牛客；公司=字节跳动；岗位=前端开发工程师 ✓（修复项） |
| 拉勾 | `产品经理-美团-拉勾网` | 来源=拉勾；公司=美团；岗位=产品经理 ✓ |
| 官网 careers（h1 含"招聘"） | h1=`网易 交互设计师 招聘` | 来源=官网；公司=网易；岗位=交互设计师 ✓（修复项） |
| 纯网站名 | `BOSS直聘` | 公司留空 → 端点 400 守卫生效，必须你手动填 ✓ |
| 同公司同岗位重复捕捉 | `腾讯招聘-UI设计师` | 去重：返回已存在岗位 id，不重复入库 ✓ |

实测覆盖 7 类真实格式 **7/7 通过**；`source_url` 全部落库、卡片可点击跳回原页。
若某站点标题格式未覆盖导致识别偏差，直接在弹窗里改公司/岗位名即可（捕捉为「确认制」，不以启发式结果为准）。
