# 秋招工作台助手 · Edge 扩展

连接本地「秋招工作台」(`http://127.0.0.1:8787`) 的浏览器扩展，提供两个能力：

1. **一键捕捉岗位** —— 在 BOSS / 牛客 / 公司官网上看到心仪岗位，点插件 → 「捕捉当前页岗位」，
   插件自动抓取页面标题/正文，启发式猜出公司名与岗位名，你确认/修改后 → 加入工作台「岗位池」。
2. **一键填网申** —— 打开公司官网网申页，点插件 → 「填网申」，选择对应企业，
   插件按表单字段的 label / name / placeholder 匹配「网申信息总汇」+「简历中心基本信息」自动填充，
   **填完请自行核对并补全缺失项**（各家 ATS 表单差异大，无法保证 100% 覆盖）。

## 前置条件

- 工作台本地服务正在运行（`uvicorn` 监听 `127.0.0.1:8787`）。
- 已在工作台「网申信息总汇」录入好复用字段（姓名 / 邮箱 / 手机 / 政治面貌 / 英语等级 …）。

## 在 Edge 中加载（开发者模式）

1. 打开 `edge://extensions`
2. 右上角打开 **开发人员模式**（Developer mode）
3. 点 **加载解压缩的扩展**（Load unpacked）
4. 选择本目录 `edge-extension/`
5. 固定插件到工具栏，开始使用

> Chrome 同理：`chrome://extensions` → 开发者模式 → 加载解压缩的扩展。

## 权限说明

- `activeTab` / `scripting`：读取当前页、注入填充脚本。
- `storage`：本地缓存。
- `host_permissions` 含 `http://127.0.0.1:8787/*`（工作台 API）与 `<all_urls>`（任意招聘/官网页可捕捉与填表）。

## 文件

- `manifest.json` —— MV3 清单
- `popup.html / popup.css / popup.js` —— 弹出页（捕捉 / 填表入口）
- `background.js` —— Service Worker，中转 API 调用（绕过扩展页 CORS）
- `content.js` —— 内容脚本，执行表单填充

## 捕捉增强（v0.2.x）

- **公司 / 来源网站分离**：`guessJob` 用「岗位关键词」（设计/产品/运营/开发/经理…）判别职位段与公司段，
  并对「腾讯招聘」「UI设计师招聘」这类尾巴自动剥掉「招聘」；**公司绝不会被识别成网站名**（BOSS直聘/牛客/拉勾/猎聘/LinkedIn 等进入黑名单守卫）。
- **来源可追溯**：捕捉保存时同时写入 `source`（站点名，如 BOSS直聘/牛客/官网）与 `source_url`（当前页 URL）。
  岗位池卡片上「🌐 来源」变为可点击链接，点开即回到原抓取页。
- **JD 抓取更准**：`extractPage` 优先抓常见 JD 容器（`.job-detail` / `.job-description` / `[class*=job-desc]` 等），回退整页正文。

## 真实站点可抓取性测试清单

> 捕捉逻辑依赖页面标题格式，且需要你已登录的会话。以下清单请在你的浏览器里逐项验证（扩展无法在自动化环境登录 BOSS/牛客）。

| 站点 | 测试动作 | 预期结果 |
| --- | --- | --- |
| BOSS直聘 岗位详情 | 打开岗位页 → 捕捉 | 来源=BOSS直聘；公司=招人公司（非 BOSS）；岗位名正确 |
| 牛客 校招岗位 | 打开岗位页 → 捕捉 | 来源=牛客；公司/岗位正确 |
| 拉勾 / 猎聘 | 打开岗位页 → 捕捉 | 来源对应；公司/岗位正确 |
| 公司官网 careers | 打开职位页 → 捕捉 | 来源=官网；公司/岗位正确 |
| 任意站点 | 标题只含网站名（如 "BOSS直聘"） | 公司留空，必须你手动填，不会把网站当公司 |
| 任意站点 | 捕捉后 | 卡片「🌐 来源」可点击跳回原页（source_url 已记录） |

离线已用 8 种真实标题格式（含「UI设计师-腾讯-BOSS直聘」「腾讯招聘-UI设计师」等）验证 `guessJob`，**8/8 通过**；
若某站点标题格式未覆盖导致识别偏差，直接在弹窗里改公司/岗位名即可（捕捉为「确认制」，不以启发式结果为准）。

## 填网申说明

- 选择企业后，`content.js` 按字段语义（姓名/邮箱/手机/学校/专业/城市/性别/生日/政治面貌/英语/毕业/学历/GPA/地址/身份证）匹配填充。
- 各家 ATS 表单结构差异大，**填充后务必自行核对并补全缺失项**。
