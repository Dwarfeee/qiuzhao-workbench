# 秋招工作台助手 · Edge 扩展

连接本地「秋招工作台」(`http://127.0.0.1:8787`) 的浏览器扩展，提供两个能力：

1. **一键捕捉岗位** —— 在 BOSS / 牛客 / 公司官网上看到心仪岗位，点插件 → 「捕捉当前页岗位」，
   插件先**按站点只抓右侧详情面板**（排除左侧岗位列表干扰），再用 **DeepSeek 智能解析**公司 / 岗位 / 薪资 / 城市 / 经验 / 学历 / JD，
   你确认/修改后 → 加入工作台「岗位池」。（DeepSeek 未配置时自动回退本地启发式。）
2. **一键填网申** —— 打开公司官网网申页，点插件 → 「填网申」，选择对应企业，
   插件先按字段语义规则填充「网申信息总汇」+「简历中心基本信息」，规则未命中的歧义字段再交给 **DeepSeek 映射**补全，
   **填完请自行核对并补全缺失项**（各家 ATS 表单差异大，无法保证 100% 覆盖）。

## 前置条件

- 工作台本地服务正在运行（`uvicorn` 监听 `127.0.0.1:8787`）。
- 已在工作台「网申信息总汇」录入好复用字段（姓名 / 邮箱 / 手机 / 政治面貌 / 英语等级 …）。

## 在 Edge 中加载（开发者模式）

1. 打开 `edge://extensions`
2. 右上角打开 **开发人员模式**（Developer mode）
3. 点 **加载解压缩的扩展**（Load unpacked）
4. 选择本目录 `edge-extension/`
5. 固定插件到工具栏，开始使用

> Chrome 同理：`chrome://extensions` → 开发者模式 → 加载解压缩的扩展。

## 权限说明

- `activeTab` / `scripting`：读取当前页、注入填充脚本。
- `storage`：本地缓存。
- `host_permissions` 含 `http://127.0.0.1:8787/*`（工作台 API）与 `<all_urls>`（任意招聘/官网页可捕捉与填表）。

## 文件

- `manifest.json` —— MV3 清单
- `popup.html / popup.css / popup.js` —— 弹出页（捕捉 / 填表入口）
- `background.js` —— Service Worker，中转 API 调用（绕过扩展页 CORS）
- `content.js` —— 内容脚本，执行表单填充

## 捕捉增强（v0.2.x）

- **站点感知提取（解决「左侧列表被混入」）**：`extractPage` 对 BOSS/牛客/拉勾/猎聘/LinkedIn 按 host 排除左侧列表/侧边栏选择器
  （如 BOSS 的 `.job-list` / `.job-card-wrapper`），只抓右侧「岗位详情主面板」；通用回退找含「职位描述/岗位职责」的最大容器。
  这是你截图里左侧一列岗位被误抓的根因修复，**无需 LLM 也生效**。
- **DeepSeek 智能解析（smart-capture）**：扩展把「干净详情文本」发给本地服务 `/api/extension/smart-capture`，
  后端复用工作台已配置的 DeepSeek（`deepseek-chat`，`json_mode`）解析出
  `company / title / salary / location / experience / education / job_type / jd_text / deadline / publish_date`，弹窗预填你确认。
  **实测**：模拟 BOSS 详情文本 → 公司=星轨科技、岗位=UI设计师、薪资=12-20K·13薪、城市=杭州、经验=1-3年、学历=本科、来源=BOSS直聘，全部正确。
  DeepSeek 未配置或解析失败时，自动回退 `guessJob` 启发式（确认制，结果以你核对的为准）。
- **公司 / 来源网站分离**：`guessJob` 用「岗位关键词」（设计/产品/运营/开发/经理…）判别职位段与公司段，
  并对「腾讯招聘」「UI设计师招聘」这类尾巴自动剥掉「招聘」；**公司绝不会被识别成网站名**（BOSS直聘/牛客/拉勾/猎聘/LinkedIn 等进入黑名单守卫）。
- **空格分隔标题也支持**：切分符在 `[-_｜|]` 基础上增加**空格**（牛客校招标题多为 `字节跳动 前端开发工程师 校招 牛客网`、官网 h1 多为 `网易 交互设计师 招聘`），
  并剔除独立的「招聘/校招/社招/实习/内推」词段，再落公司/岗位；避免公司被识别为空只能手填。
- **来源可追溯**：捕捉保存时同时写入 `source`（站点名，如 BOSS直聘/牛客/官网）与 `source_url`（当前页 URL）。
  岗位池卡片上「🌐 来源」变为可点击链接，点开即回到原抓取页。

## 填网申说明

- 选择企业后，`content.js` 先做**规则填充**：按字段语义（姓名/邮箱/手机/学校/专业/城市/性别/生日/政治面貌/英语/毕业/学历/GPA/地址/身份证）匹配。
- 规则未命中的字段（如「最高学历」「英语水平」「所在院系」），扩展把**字段显示名**（不含你的真实值）发给 `/api/extension/smart-fill-map`，
  由 DeepSeek 映射到规范键后二次补填。**实测**：最高学历→degree、英语水平→english、所在院系→school，无对应项返回 null。
- **隐私**：规则填充用本地数据；LLM 映射只发送「字段名」，绝不发送姓名/电话/身份证等真实个人信息。
- 各家 ATS 表单结构差异大，**填充后务必自行核对并补全缺失项**。
